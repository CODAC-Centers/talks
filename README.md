# CODAC talks

The slide decks of the AFOSR Center of Excellence CODAC, served by GitHub Pages
at **https://codac-centers.github.io/talks/**. Start from the
[kickoff meeting](https://codac-centers.github.io/talks/kom-2026/).

This repository holds the **built** talks. Every commit here is one snapshot of
the site, published by CI. **Do not edit anything in this repository.** It is
overwritten in full on every build, so changes made here are lost.

The talks' sources live in a separate, private repository in this
organisation. If you are a center member and want to change a talk, work
there. If you are not and you have found a problem, please email
fairbanksj [at] ufl [dot] edu.

The decks are [reveal.js](https://revealjs.com): arrow keys navigate, `Esc`
shows the overview, and `S` opens the speaker view. The slides are copyright
their authors, all rights reserved.
